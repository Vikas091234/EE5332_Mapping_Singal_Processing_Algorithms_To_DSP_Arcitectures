# EE5332 — Mapping Signal Processing Algorithms to DSP Architectures

Coursework and selected hardware-oriented implementations from **EE5332 at IIT Madras**, covering DSP algorithms, FIR filtering, Vitis HLS optimization, FPGA interfaces, and a 2D convolution accelerator evaluated across multiple hardware design points.

## Highlights

- SystemVerilog RTL design and testbenches
- FIR filter implementation and verification in C
- Vitis HLS synthesis and directive-based optimization
- AXI-Stream and AXI-Lite interfaces
- PYNQ/Zynq FPGA implementation
- 2D convolution acceleration using line buffers and sliding windows
- Floating-point and fixed-point datapaths
- Pipeline/unroll design-space exploration
- Multichannel/RGB convolution
- Hardware-versus-software validation and performance comparison

## Course Project — 2D Convolution Accelerator

The project implements a **K×K convolution accelerator (K=3 or 5)** for grayscale/RGB images using a streaming architecture with a **line buffer and sliding window**.

The implementation explores five design points:

| Design point | Architecture | Key focus |
|---|---|---|
| 01 | Baseline 3×3 | Streaming baseline |
| 02 | Float 3×3 | Pipeline + loop unrolling |
| 03 | Fixed-point 3×3 | `ap_fixed<16,3>` datapath |
| 04 | Float 5×5 | Larger convolution kernel |
| 05 | Multichannel | Runtime-configurable RGB/multichannel design |

The project includes software references, HLS implementations, test benches, synthesis reports, PYNQ validation notebooks, and written analysis.
